## Введение

Данное приложение представляет собой инструмент для работы с текстами на эсперанто, предоставляющий следующие возможности:

- Замена корней слов эсперанто на их переводы (русский язык, иероглифы и др.)
- Добавление руби-аннотаций над эсперанто-словами в HTML-формате
- Различные форматы вывода (HTML с руби, формат со скобками и др.)
- Сохранение исходных частей текста или их локальная обработка
- Возможность создания собственных правил замены через генератор JSON-файлов

Приложение состоит из двух основных частей:
1. **Главная страница** – для обработки текста на эсперанто
2. **Генератор JSON-файлов** – для создания файлов с правилами замены

## Начало работы

При первом запуске приложения вы увидите главную страницу с заголовком "Заменять иероглифы в эсперанто-тексте и добавлять руби в формате HTML". Для успешной работы с приложением рекомендуется следовать этим шагам:

1. Решите, будете ли вы использовать стандартный JSON-файл с правилами замены или создадите собственный
2. Если требуется собственный JSON, перейдите к странице "Генератор JSON-файлов для замены"
3. После подготовки правил замены вернитесь на главную страницу для обработки текста

## Главная страница приложения

### Загрузка JSON-файла с правилами замены

Первым шагом нужно определить, какой JSON-файл с правилами замены вы будете использовать:

1. Выберите один из вариантов:
   - **Использовать по умолчанию** – приложение загрузит встроенный файл с правилами замены
   - **Загрузить** – для использования собственного JSON-файла

2. Если вам нужен пример JSON-файла, разверните секцию "**Пример JSON (файл для замены)**" и нажмите кнопку "Скачать пример JSON".

### Ввод эсперанто-текста

После загрузки правил замены нужно ввести текст на эсперанто для обработки:

1. В разделе "Источник входного текста" выберите способ ввода:
   - **Ввести вручную** – для непосредственного ввода текста
   - **Загрузить из файла** – для загрузки текстового файла в формате UTF-8

2. Если выбран ручной ввод, введите или вставьте текст на эсперанто в текстовое поле.

3. Если выбрана загрузка из файла, используйте кнопку загрузки для выбора файла с текстом.

### Выбор формата вывода

Приложение предлагает несколько форматов для обработанного текста:

1. Выберите один из следующих форматов:
   - **HTML формат (Ruby-символы, изменение размера)** – создает HTML с руби-аннотациями, автоматически регулируя размер руби в зависимости от длины текста
   - **HTML формат (Ruby-символы, изменение размера, замена иероглифов)** – аналогичный формат, но с иероглифами в качестве основного текста и эсперанто в руби
   - **HTML формат** – простой HTML с руби-аннотациями без изменения размера
   - **HTML формат (замена иероглифов)** – простой HTML с иероглифами в качестве основного текста
   - **Формат со скобками** – текст на эсперанто с переводом в скобках
   - **Формат со скобками (замена иероглифов)** – перевод с эсперанто-текстом в скобках
   - **Только замененная строка (простая замена)** – только результат замены без дополнительного форматирования

### Формат символов эсперанто

Выберите формат для специальных символов эсперанто:

- **Надстрочные диакритические знаки** – использование символов с надстрочными знаками (ĉ, ĝ, ĥ...)
- **x-формат** – использование латинских букв с x (cx, gx, hx...)
- **^-формат** – использование латинских букв со знаком ^ (c^, g^, h^...)

### Расширенные настройки

В разделе "Расширенные настройки" можно настроить параллельную обработку:

1. Разверните секцию "Настройки параллельной обработки"
2. При необходимости включите параллельную обработку, установив флажок "Использовать параллельную обработку"
3. Укажите количество процессов (от 2 до 4), которые будут использоваться для обработки текста

### Получение результатов

После настройки всех параметров:

1. Нажмите кнопку "Отправить" для обработки текста
2. Результат будет показан ниже в соответствующем формате:
   - Для HTML-форматов будет доступен предварительный просмотр и вкладка с исходным HTML-кодом
   - Для других форматов будет показан только текст результата
3. Используйте кнопку "Скачать результат замены" для сохранения обработанного текста в файл

## Генератор JSON-файлов для замены

Чтобы перейти к генератору JSON-файлов, воспользуйтесь навигацией Streamlit в левой части экрана.

### Подготовка CSV-файла

Первым шагом нужно подготовить или выбрать CSV-файл, содержащий соответствия между корнями эсперанто и их переводами:

1. В разделе "Шаг 1: Подготовить CSV-файл" выберите один из вариантов:
   - **Загрузить файл** – для использования собственного CSV-файла
   - **Использовать по умолчанию** – для использования встроенного файла

2. В разделе "Список примеров файлов" вы можете скачать примеры CSV-файлов:
   - **Пример CSV1** – корни эсперанто с русским переводом и руби
   - **Пример CSV2** – корни эсперанто с иероглифами (версия Mingeo)
   - **Пример CSV3** – корни эсперанто с иероглифами

3. Формат CSV должен содержать в первой колонке корень эсперанто, а во второй – соответствующий перевод или иероглифы.

### Подготовка JSON-файлов

На втором шаге нужно подготовить или выбрать JSON-файлы с правилами разбора корней и настройками замены:

1. Для JSON-файла с правилами разбора корней эсперанто выберите:
   - **Загрузить** – для использования собственного файла
   - **Использовать по умолчанию** – для использования встроенного файла

2. Для JSON-файла с настройками строк замены также выберите:
   - **Загрузить** – для использования собственного файла
   - **Использовать по умолчанию** – для использования встроенного файла

3. В разделе "Список примеров файлов" можно скачать примеры этих JSON-файлов:
   - **Пример JSON1** – настройки разбора корней эсперанто
   - **Пример JSON2** – настройки итоговой строки замены

### Создание итогового JSON-файла

После подготовки всех необходимых файлов:

1. Выберите формат вывода, который будет использоваться при обработке текста (этот выбор должен совпадать с выбором на главной странице)

2. При необходимости настройте параллельную обработку в разделе "Шаг 3: Расширенные настройки"

3. Нажмите кнопку "Создать JSON-файл для замены"

4. После успешной генерации файла используйте кнопку "Скачать итоговый список для замены" для сохранения созданного JSON-файла

5. Теперь вы можете вернуться на главную страницу и загрузить созданный файл для использования при обработке текста

## Специальные возможности

### Использование маркеров % и @

Приложение поддерживает специальные маркеры для контроля процесса замены:

1. **Маркер %** – текст, заключенный в символы % (формат `%<строка до 50 символов>%`), не будет заменен и сохранится в исходном виде.

   Пример: `La %Esperanto% estas bela lingvo.` → Слово "Esperanto" останется без изменений

2. **Маркер @** – текст, заключенный в символы @ (формат `@<строка до 18 символов>@`), будет заменен локально, с учетом правил замены.

   Пример: `La @Esperanto@ estas bela lingvo.` → Слово "Esperanto" будет заменено согласно правилам, но независимо от контекста

### Форматы вывода

Доступны различные форматы вывода, каждый со своими особенностями:

1. **HTML-форматы с руби** – добавляют маленький текст над основным текстом, как в японском фуригана:
   ```html
   <ruby>lingvo<rt>язык</rt></ruby>
   ```

2. **Форматы с изменением размера** – автоматически регулируют размер руби в зависимости от длины текста

3. **Форматы с заменой иероглифов** – меняют местами основной текст и руби, делая перевод основным текстом

4. **Форматы со скобками** – представляют результат в виде "основной_текст(перевод)" или "перевод(основной_текст)"

### Параллельная обработка

Для ускорения обработки больших текстов вы можете использовать параллельную обработку:

1. В разделе "Расширенные настройки" на главной странице включите параллельную обработку

2. Установите количество процессов в зависимости от возможностей вашего компьютера

3. При генерации JSON-файла также можно использовать параллельную обработку, что особенно полезно при большом количестве корней

---

Это приложение предоставляет гибкие возможности для обработки текстов на эсперанто и добавления переводов или аннотаций. Используя различные настройки и форматы вывода, вы можете создавать тексты с руби-аннотациями, что особенно полезно для изучения эсперанто или создания учебных материалов.
