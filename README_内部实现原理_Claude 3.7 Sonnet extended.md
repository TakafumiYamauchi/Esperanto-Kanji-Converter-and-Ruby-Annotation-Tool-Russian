## Общая архитектура приложения

Данное приложение представляет собой веб-инструмент, созданный с использованием фреймворка Streamlit, для замены текста на эсперанто и генерации руби-аннотаций. Архитектурно приложение состоит из двух основных компонентов:

1. **Основной компонент обработки текста** (`main.py`) — обрабатывает ввод пользователя, выполняет замены и форматирует выходные данные.
2. **Генератор JSON-файлов** (`JГенератор JSON-файлов для замены (иероглифов) в эсперанто-тексте.py`) — отдельный инструмент для создания пользовательских файлов замены.

Эти компоненты поддерживаются двумя специализированными модулями:

- `esp_text_replacement_module.py` — содержит функции для различных типов замены текста.
- `esp_replacement_json_make_module.py` — содержит функции для создания и модификации JSON-файлов замены.

Приложение использует подход, основанный на замене строк с помощью словарей и списков соответствия, а также механизм плейсхолдеров для обеспечения точных замен без конфликтов.

Ключевые компоненты включают:

## Ключевые алгоритмы и процессы

### Процесс обработки текста

Процесс обработки текста в приложении состоит из следующих этапов:

1. **Предварительная обработка текста**:
   - Нормализация пробелов (`unify_halfwidth_spaces`)
   - Преобразование символов эсперанто в единый формат (`convert_to_circumflex`)

2. **Обработка специальных маркеров**:
   - Обнаружение и сохранение участков текста, обрамлённых `%` (для пропуска замен)
   - Обнаружение и специальная обработка участков текста, обрамлённых `@` (для локализованной замены)

3. **Основной процесс замены**:
   ```python

       text, 
       placeholders_for_skipping_replacements,
       replacements_list_for_localized_string,
       placeholders_for_localized_replacement,
       replacements_final_list,
       replacements_list_for_2char,
       format_type
   ```

   Этот метод работает следующим образом:
   - Заменяет участки, которые нужно пропустить, на временные плейсхолдеры
   - Выполняет локализованные замены для участков с маркером `@`
   - Применяет глобальные замены из `replacements_final_list`
   - Применяет замены для двухбуквенных корней
   - Восстанавливает плейсхолдеры в окончательный текст
   - Форматирует результат в соответствии с выбранным форматом

4. **Форматирование результата**:
   - Применение HTML-заголовков и стилей для руби (при необходимости)
   - Преобразование между форматами символов эсперанто
   - Создание окончательного вывода

### Механизм генерации JSON-файлов

Процесс создания JSON-файла с правилами замены включает:

1. **Импорт исходных данных**:
   - Загрузка CSV с соответствиями корней эсперанто
   - Загрузка пользовательских настроек разбора корней
   - Загрузка дополнительных настроек строк замены

2. **Создание временных словарей замен**:
   ```python
   temporary_replacements_dict = {}

       if pd.notna(E_root) and pd.notna(hanzi_or_meaning) \

               len(E_root)
   ```

3. **Преобразование словаря в списки замен с сортировкой по приоритету**:
   - Создание списка кортежей `(old, new, placeholder)`
   - Сортировка по длине строки (длинные строки имеют приоритет)

4. **Расширение базовых замен**:
   - Добавление производных форм глаголов (с окончаниями -as, -is, -os и т.д.)
   - Обработка суффиксов и префиксов

5. **Создание трёх основных списков замен**:
   - `replacements_final_list` — для глобальных замен
   - `replacements_list_for_localized_string` — для локализованных замен
   - `replacements_list_for_2char` — для двухбуквенных корней

6. **Объединение всех списков в один JSON-файл**:
   ```python

   combined_data["局部文字替换用のリスト(列表)型配列(replacements_list_for_localized_string)"] = replacements_list_for_localized_string
   ```

## Система плейсхолдеров и замен

Одним из ключевых аспектов приложения является его система плейсхолдеров, которая обеспечивает безопасные замены без конфликтов:

### Функция safe_replace

```python
def safe_replace(text: str, replacements: List[Tuple[str, str, str]]) -> str:
    """
    Принимает список кортежей (old, new, placeholder) и выполняет
    двухэтапную замену: text в котором old → placeholder → new
    """
    valid_replacements = {}
    # Сначала old→placeholder
    for old, new, placeholder in replacements:
        if old in text:
            text = text.replace(old, placeholder)
            valid_replacements[placeholder] = new
    # Затем placeholder→new
    for placeholder, new in valid_replacements.items():
        text = text.replace(placeholder, new)
    return text
```

Этот подход решает распространённую проблему замены строк, когда прямая последовательная замена может привести к конфликтам или непредсказуемым результатам. Вместо этого:

1. Все исходные строки сначала заменяются уникальными плейсхолдерами
2. Затем все плейсхолдеры заменяются целевыми строками

Приложение использует три типа плейсхолдеров:
- `placeholders_for_skipping_replacements` — для участков, обрамлённых `%`
- `placeholders_for_localized_replacement` — для участков, обрамлённых `@`
- `imported_placeholders_for_global_replacement` — для основных замен

Плейсхолдеры загружаются из текстовых файлов, содержащих уникальные строки, которые маловероятно встретятся в обычном тексте.

## Работа с форматами текста эсперанто

Приложение поддерживает различные форматы символов эсперанто:

1. **Символы с надстрочными знаками** (ĉ, ĝ, ĥ...)
2. **x-формат** (cx, gx, hx...)
3. **^-формат** (c^, g^, h^...)

Для преобразования между этими форматами используются словари отображения:

```python
x_to_circumflex = {'cx': 'ĉ', 'gx': 'ĝ', ...}
circumflex_to_x = {'ĉ': 'cx', 'ĝ': 'gx', ...}
x_to_hat = {'cx': 'c^', 'gx': 'g^', ...}
hat_to_x = {'c^': 'cx', 'g^': 'gx', ...}
hat_to_circumflex = {'c^': 'ĉ', 'g^': 'ĝ', ...}
circumflex_to_hat = {'ĉ': 'c^', 'ĝ': 'g^', ...}
```

Функция `replace_esperanto_chars` принимает текст и словарь отображения, применяя соответствующие замены:

```python
def replace_esperanto_chars(text, char_dict: Dict[str, str]) -> str:
    for original_char, converted_char in char_dict.items():
        text = text.replace(original_char, converted_char)
    return text
```
